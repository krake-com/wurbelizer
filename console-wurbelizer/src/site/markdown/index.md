# Wurbelizer Console

A command-line wrapper that runs the Wurbelizer from the console, without a build
tool. Classes live under `org.wurbelizer.console.*`.

This runner is **illustrative** — it shows how to invoke the wurbiler and wurbler
directly and is handy for experiments and quick demos. For production builds, use
the [Wurbelizer Maven Plugin](../wurbelizer-maven-plugin/index.html) or the
[Ant Wrapper](../ant-wurbelizer/index.html) instead.
