The Wurbelizer is a code generator for Java, written in Java, 
using Java as its template language and embedded within 
Java sources. It does not create source files as a whole, 
but modifies well-defined regions of code. 
It integrates via Maven-plugins, is available from Maven Central 
and hosted at Bitbucket as Open Source according to the LGPL.

For an overview and how it works, please visit [wurbelizer.org](https://wurbelizer.org).

More info can be found in the [wiki](https://bitbucket.org/krake-oss/wurbelizer/wiki/Home).
